## 🤖 Язык нового поколения

**TOXA** — это не просто ещё один учебный язык. Это **язык программирования нового поколения**, который показывает, как современные технологии меняют сам процесс создания языков.

### Что значит «нового поколения»?

- 🧠 **Создан с помощью ИИ.** Весь интерпретатор, синтаксис, справка и документация разработаны в диалоге с искусственным интеллектом. То, на что раньше уходили месяцы работы команды, сейчас можно сделать за несколько часов — и TOXA это доказывает.
- 🇷🇺 **Русский синтаксис.** Читается как обычный текст: `вывести`, `пусть`, `если`, `пока`, `функция`. Никаких `print`, `let`, `if` — только понятные слова.
- ⚡ **Лёгкий и быстрый.** Ноль зависимостей. Один файл `toxa.py` — и всё работает. Запускается на любом Python 3.8+.
- 🎓 **Создан для обучения.** Идеален для тех, кто только начинает программировать: не нужно бороться с английским синтаксисом, чтобы понять логику.
- 🔮 **Открыт к развитию.** Добавляй свои команды, расширяй язык, экспериментируй — всё просто и прозрачно.

> 💡 **Главная идея:** языки программирования больше не создаются годами. С ИИ можно сделать свой язык за вечер — и TOXA тому пример.

## Возможности

- 📝 **Русский синтаксис** — `вывести`, `пусть`, `если`, `пока`, `функция`
- 🖨️ **Печать** — `вывести`, `вывод`, `напечатать`
- 📦 **Переменные** — `пусть x = 10` или просто `x = 10`
- ⌨️ **Ввод с клавиатуры** — `ввод имя`, `ввод число возраст`
- 🔀 **Условия** — `если / иначе если / иначе`
- 🔁 **Циклы** — `пока` (while) и `повтор N` (повторить N раз)
- 🧩 **Функции** — `функция f(a, b) { вернуть ... }`
- 🛠️ **Встроенные функции** — `длина`, `корень`, `модуль`, `случайное`, `верх`, `низ`
- 💬 **REPL** — интерактивная консоль
- 📄 **Шаблоны** — `toxa new hello` создаёт готовый файл
- 📚 **Встроенная справка** — `toxa help`
- 🤖 **Создан с помощью ИИ** — весь код и документация

## Установка

### Требования

- **Python 3.8+**
- Любая ОС: Windows, Linux, macOS

### Шаги

1. Склонируй репозиторий:

   ```bash
   git clone https://github.com/TOXAIAZIK/toxa.git
   cd toxa
   ```

2. Проверь Python:

   ```bash
   python --version
   ```

   На Windows может понадобиться `py` вместо `python`.

3. Запусти справку для проверки:

   ```bash
   python toxa.py help
   ```

Никаких сторонних библиотек не требуется — только стандартная библиотека Python.

## Синтаксис языка

### Вывод

```toxa
вывести "Hello World!"
вывести 2 + 2
вывести "x = " + x
```

Синонимы: `вывод`, `напечатать`.

### Переменные

```toxa
пусть имя = "Аня"
пусть возраст = 25
возраст = 26          # короткая форма тоже работает
```

### Ввод

```toxa
ввод имя              # строка
ввод число возраст    # число
```

### Условия

```toxa
если x > 10 {
    вывести "большое"
} иначе если x > 5 {
    вывести "среднее"
} иначе {
    вывести "маленькое"
}
```

### Циклы

```toxa
# while
пусть i = 1
пока i <= 5 {
    вывести i
    i = i + 1
}

# повторить N раз
повтор 3 {
    вывести "ку-ку"
}
```

### Функции

```toxa
функция сумма(a, b) {
    вернуть a + b
}

вывести сумма(2, 3)      # 5
```

### Встроенные функции

| Функция | Что делает | Пример |
|---|---|---|
| `длина(s)` | длина строки | `длина("привет")` → `6` |
| `корень(x)` | квадратный корень | `корень(16)` → `4.0` |
| `модуль(x)` | модуль числа | `модуль(-5)` → `5` |
| `случайное(a, b)` | случайное целое от a до b | `случайное(1, 6)` |
| `верх(s)` | верхний регистр | `верх("abc")` → `ABC` |
| `низ(s)` | нижний регистр | `низ("ABC")` → `abc` |

### Комментарии

```toxa

```

## Команды CLI

```bash
python toxa.py                    # открыть REPL
python toxa.py help               # справка по всем командам

python toxa.py run hello.toxa     # запустить программу
python toxa.py hello.toxa         # то же самое (короче)

python toxa.py examples           # показать пример программы
python toxa.py repl               # открыть REPL явно
```

## Примеры

### Угадай число

```toxa
пусть секрет = случайное(1, 100)
пусть попыток = 0

пока 1 == 1 {
    ввод число догадка
    попыток = попыток + 1

    если догадка == секрет {
        вывести "Угадал! Попыток: " + попыток
        вернуть 0
    } иначе если догадка < секрет {
        вывести "Больше"
    } иначе {
        вывести "Меньше"
    }
}
```

### Таблица умножения

```toxa
функция таблица(n) {
    пусть i = 1
    пока i <= 10 {
        вывести n + " × " + i + " = " + n * i
        i = i + 1
    }
}

таблица(7)
```

### Факториал

```toxa
функция факториал(n) {
    если n <= 1 {
        вернуть 1
    }
    вернуть n * факториал(n - 1)
}

вывести факториал(5)     # 120
```

## Сборка в .exe

Можно упаковать интерпретатор в один исполняемый файл через **PyInstaller**:

```bash
pip install pyinstaller
pyinstaller --onefile --name toxa toxa.py
```

Готовый файл появится в `dist/toxa.exe` (Windows) или `dist/toxa` (Linux/macOS).

Запуск:

```bash
dist/toxa.exe help
dist/toxa.exe run hello.toxa
```

## 🧠 О проекте

TOXA создан **с помощью искусственного интеллекта** в формате диалога: идея, синтаксис, интерпретатор, справка и документация рождались шаг за шагом в разговоре с ИИ.

Это демонстрация того, как **языки программирования нового поколения** могут создаваться быстрее, проще и доступнее. Раньше для создания языка нужны были годы, команда и компиляторщики. Сейчас — идея, желание и хороший диалог с ИИ.

Если ты тоже хочешь сделать свой язык — **начни прямо сегодня**. TOXA показывает: это реально.
